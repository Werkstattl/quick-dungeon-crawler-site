Update 4.1.0 replaces the unrestricted six-item loadout with six dedicated equipment slots.

## Six dedicated slots

Every loadout now has one slot for each equipment role:

- **Weapon**
- **Off Hand**
- **Head**
- **Body**
- **Feet**
- **Accessory**

Inventory comparisons now match an item against the equipment in the same slot. Equip Best also evaluates every slot separately, which makes loadouts easier to understand and manage.

## Safe migration for existing saves

Existing saves migrate automatically. One item remains equipped in each slot, while extra same-slot items return to the inventory. No equipment is deleted during the migration.

Existing players also receive a free **Level 100 Heirloom Accessory**. Its tier matches the highest unlocked Curse Level, and it includes a guaranteed Dodge stat.

## More fixes

- Auto Mode now keeps Level 100 as an auto-sell threshold.
- The stats help panel has clearer labels and the correct opening sound.
- Translation attributes are restricted to a safe allowlist.

Update 3.8.4 is live with a new visual feature, important bugfixes, and expanded language support.

## Highlights

- **Enemy Type Badges** — Enemies now display their modifier type as a colored badge in combat. Five types exist: *Offensive*, *Defensive*, *Balanced*, *Quick*, and *Lethal*. Watch out for *Offensive* and *Lethal* enemies — they can hit very hard, especially on bosses.
- **Saving Bugfixes** — Improved save stability to prevent data loss during gameplay.
- **Improved Translations** — Fixed and expanded translations for all supported languages.

## Smaller improvements

- Enemy type badges are now fully translated across all 17 supported languages.
- Various internal fixes and improvements.

Thank you for all the feedback and ideas — they help make the game better!

Update 4.4.2 makes importing and exporting your progress more reliable and gives clearer feedback when something goes wrong.

## Copy save codes with confidence

Export-code copying has been improved, especially on Android. The **Copied!** confirmation now appears only after the code has actually been copied.

Exports also handle special characters in save data correctly, fixing failures caused by those characters.

## Clearer import errors

Invalid or incomplete save codes and storage problems now produce clearer error messages. If imported data cannot be saved, **your existing save is preserved**.

The new messages are translated into all **31 supported languages**.

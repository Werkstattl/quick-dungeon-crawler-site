Update 4.4.2 tightens the save transfer between devices. Export codes, the copy button and the import checks all handle their edge cases properly now.

## Export codes that survive special characters

Hero names and other text with umlauts or other special characters no longer break the export code. The code keeps the same Base64 format, so it stays readable by older game versions as well.

If the clipboard refuses the copy - which can happen on some Android devices - the game no longer claims success. **"Copied!" only appears after the code was actually copied**. On failure, the export field is pre-selected for a manual copy and a message explains what to do instead.

## Imports tell you what went wrong

Pasting an invalid or incomplete export code no longer just does nothing: you now get a clear message to copy the entire export code from the old device and try again.

The import confirmation dialog is also no longer English-only. It is fully translated and spells out what an import means: **your current save is replaced and the current dungeon run resets**, while inventory, equipped items, gold and permanent unlocks come from the imported save.

## Your current save stays intact

Before switching to the imported save, the game now writes it to storage first. If that write fails - for example because the device is full - **your current game remains untouched and playable**, the error message says so, and you can free up storage and retry.

## Translations

All new messages ship in **all 31 supported languages**.
